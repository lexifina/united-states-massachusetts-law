# Section 20: Payroll, financial and other data in centralized state accounting and payroll systems
Section 20. For requests of payroll, financial and other data residing in the centralized state accounting and payroll systems, or associated data warehouses, the comptroller shall make available guidelines on how agencies using these systems may access and disclose public records to ensure that data that is exempted or prohibited from disclosure is not wrongfully disclosed and the security of the system is maintained.
