# Section 6A: Code of Massachusetts Regulations; publication
Section 6A. Prior to publication of the first issue of the Massachusetts Register, the state secretary shall first cause to be published all currently effective agency regulations in a special publication of the Massachusetts Register to be designated as the ''Code of Massachusetts Regulations''.
The state secretary shall regulate the supplementation and the collation and republication of the printed codification with a view to keeping the Code of Massachusetts Regulations as current as possible.
