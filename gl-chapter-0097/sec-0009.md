# Section 9: Zones, designation
Section 9. As established for use in the mainland zone, said system shall be named, and in any land description in which it is used it shall be designated, the ''Massachusetts Coordinate System, NAD 1983, Mainland Zone''. As established for use in the island zone, said system shall be named, and in any land description in which it is used it shall be designated, the ''Massachusetts Coordinate System, NAD 1983, Island Zone''.
